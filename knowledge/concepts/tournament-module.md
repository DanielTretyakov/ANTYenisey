# Tournament Module

Один из трёх «движков» платформы [[concepts/yenisey-platform-overview]], входящий в Этап 1. Реализует проведение турниров клуба. Рейтинг участника на текущем этапе — справочное поле без расчёта и без проверки допуска; тема отложена до появления источника актуальных данных.

## Key Points

- **6 типов турниров «Енисея»**: Абсолют, Клуб 50, Клуб 100, Клуб 200, Клуб 300, Пятничное турне.
- **Рейтинг-число в названии турнира — справочное**: цифра (50/100/200/300) исторически обозначает уровень, но сейчас не используется для проверки допуска — данных актуального рейтинга нет.
- **Рейтинг участника откладывается**: поле существует в модели данных как опциональное справочное, без автоматического расчёта и без бизнес-правил допуска.
- **Публичная карточка тренера**: фото, достижения, инвентарь, цены, ссылки на соцсети — новый сценарий, добавленный в Этапе 1.

## Details

Академия «Енисей» проводит турниры нескольких форматов. «Абсолют» — открытый турнир без ограничений по уровню. «Клуб 50/100/200/300» — турниры с рейтинговым ориентиром в названии; однако поскольку нет доступного источника актуального рейтинга игроков (например, от федерации), проверка допуска по рейтингу не реализуется на Этапе 1. «Пятничное турне» — регулярный еженедельный турнир.

Публичная карточка тренера появилась как отдельный сценарий: страница тренера доступна публично (не требует авторизации), содержит маркетинговую информацию. Это влияет на модель данных — сущность `Coach` должна иметь публичные поля (bio, achievements, equipment, social_links, pricing) отдельно от административных (расписание, внутренние заметки).

Турнир как тип услуги в [[concepts/booking-payment-engine]] следует той же двухстадийной схеме оплаты: запись на турнир → холд → списание после завершения/факта участия.
