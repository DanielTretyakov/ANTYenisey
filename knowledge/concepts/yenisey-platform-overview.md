# Yenisey Platform Overview

Веб-платформа (SaaS) для клубов настольного тенниса, тиражируемая с первого этапа. Академия настольного тенниса «Енисей» (Новосибирск, владелец — Андрей Шулепин) является пилотным клубом и не платит подписку. Продукт строится вокруг трёх «движков», вводимых поэтапно.

## Key Points

- **SaaS с мультиарендностью**: `tenant_id` — рабочее требование Этапа 1, не будущая оптимизация; каждый клуб изолирован в рамках одного инстанса.
- **Три движка**: (1) бронирование/оплата услуг, (2) CRM с персданными, (3) проведение турниров и рейтинг.
- **Три этапа**: Этап 1 = движок бронирования + подписка для клубов; Этап 2 = продажа инвентаря; Этап 3 = модуль «спортшкола» (тренировочные группы).
- **Пилот без оплаты**: «Енисей» использует платформу бесплатно; первые платящие клубы — цель монетизации.
- **Настраиваемый профиль клуба** — одно из требований Этапа 1 наряду с доступом к движку бронирования.

## Details

Бизнес-владелец первоначально описывал продукт как сервис для одного клуба, однако в процессе уточнения требований (август 2026) сформулировал модель как тиражируемый SaaS: главная цель — быстрый выход на выручку через продажу подписок другим клубам, а «Енисей» — лишь пилот для обкатки.

Движок бронирования/оплаты охватывает четыре типа услуг: индивидуальные тренировки, турниры, спарринги (аренда стола тренером для пары) и аренда стола или робота. Каждый тип услуги имеет собственную логику записи, оплаты и отмены — подробнее в [[concepts/booking-payment-engine]].

Подписочная модель для клубов предполагает автоплатежи через ЮKassa и три тарифа. Подробнее — в [[concepts/club-subscription-billing]].

Мультиарендность обеспечивается полем `tenant_id` на всех ключевых сущностях БД с первого этапа, чтобы не переписывать схему при добавлении новых клубов. Профиль клуба (название, логотип, прайс-листы, тренеры) настраивается администратором клуба.
