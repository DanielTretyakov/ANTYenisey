# «Енисей»

SaaS-платформа для клубов настольного тенниса: онлайн-запись на тренировки,
турниры и спарринги, аренда столов и роботов, приём оплаты, личный кабинет
клиента и CRM для администрации.

Продукт с самого начала строится как тиражируемый сервис, а не как внутренний
инструмент одного клуба. АНТ «Енисей» — первый клиент платформы, на котором
она обкатывается. Мультиарендность и настройка под конкретный клуб (залы,
столы, цены, шаг бронирования, политика отмены) заложены с первого этапа.

## Что внутри

```
apps/api         NestJS: REST API, авторизация, бизнес-логика
apps/web         Next.js (app router): интерфейс и личный кабинет
packages/database Prisma — единственный владелец схемы БД
packages/types   общий контракт HTTP между api и web
docs/            ТЗ, инструкция по разработке, дизайн-система
```

Стек: TypeScript, pnpm 10 + Turborepo, PostgreSQL 18.

## Быстрый старт

Нужны Node ≥ 22, pnpm 10 и PostgreSQL 18. Подробности первого запуска, включая
создание баз и учётных записей сотрудников, — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

```bash
pnpm install
cp .env.example .env          # заполнить пароль БД и два РАЗНЫХ JWT-секрета
pnpm db:generate
pnpm --filter @yenisey/database migrate
pnpm --filter @yenisey/database seed
pnpm dev                      # api :3001, web :3000
```

## Ежедневные команды

```bash
pnpm dev            # оба приложения в watch-режиме
pnpm typecheck      # проверка типов по всем пакетам
pnpm test           # модульные тесты (node --test)
pnpm smoke          # 196 сценариев против поднятого API и живого Postgres
pnpm db:migrate
pnpm db:studio
```

`pnpm build` нельзя запускать поверх работающего `pnpm dev` — оба пишут в один
`apps/web/.next`, и сборка затирает чанки живого dev-сервера. Подробности и
обход через `NEXT_DIST_DIR` — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
