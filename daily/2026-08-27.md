## Memory Maintenance

### Session (17:05)

**Context:** Большая сессия по продукту «Енисей» — финальная проверка, фикс тестов схемы, коммит и закрытие сессии.

**Key Exchanges:**
- Финальная проверка перед закрытием сессии выявила, что `schema-tests.sql` отстал от миграций: фикстуры вставляли данные по старым колонкам (клуб с ценами, стол без зала, пользователь без телефона). Ни типы, ни модульные тесты этого не видели — только `psql` на одноразовой базе.
- Чинил тесты схемы inline Python-скриптами через heredoc — снова столкнулся с проблемой экранирования, пришлось переписывать блоки.

**Decisions Made:**
- Тесты схемы обновлены под текущие миграции: клуб без цен (цены ушли в зал), стол привязан к залу, у пользователя обязательны телефон и дата рождения.
- Записано в долгую память: `pnpm smoke` и `verify` ловят ошибки, невидимые для типов и модульных тестов (за сессию таких было семь).

**Lessons Learned:**
- `schema-tests.sql` — третий уровень защиты после типов и модульных тестов; его легко забыть при изменении схемы, потому что он вне pnpm pipeline и не ломает CI автоматически.
- Inline Python через heredoc в Bash по-прежнему ненадёжен из-за экранирования — использовать `Edit` / `Write`.

**Action Items:**
- Заглушки контактов `+70000000000` / `01.01.1900` у сотрудников — заменить вручную, когда появится редактирование человека в составе.
- Причина пропажи трёх столов из сида в начале сессии не найдена — наблюдать в следующих сессиях.
